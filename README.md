# CAP Droit

Application gratuite et sans publicité pour réviser le droit, de la L1 au CRFPA : cours, articles des codes, grands arrêts, QCM, cas pratiques corrigés, méthodologie, lexique et calcul des délais.

- Version web : https://lonisbouss-cmyk.github.io/cap-droit/
- APK Android : onglet Releases
